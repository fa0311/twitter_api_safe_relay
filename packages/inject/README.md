# twitter-api-safe-inject

The canonical MAIN-world setup script used by `twitter-api-safe-request` and browser extensions to discover the Twitter/X Web App API client.

## Asset path

Resolve `twitter-api-safe-inject/setup.js` with your runtime or bundler, then inject the resulting JavaScript before the X web application initializes.

This package relies on X's unpublished internal implementation and may break without notice.
